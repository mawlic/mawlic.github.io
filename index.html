Hermes Fleet Monitoring

This is a private, single-operator monitoring integration. It receives Grafana alert emails in the operator's Gmail inbox, investigates the affected services using Grafana telemetry, and sends a concise incident assessment to the operator's encrypted Matrix room. It does not provide public accounts or sign-ups.

Google access is limited to read-only Gmail for detecting and reading alert messages. The integration cannot send, delete, or modify mail. It uses Gmail push notifications and Google Cloud Pub/Sub for event-driven activation.

For details about data use, storage, sharing, and revocation, read the Privacy Policy.
