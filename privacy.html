Privacy Policy — Hermes Fleet Monitoring

Last updated: 2026-11-07

This policy covers a private, single-operator Hermes Fleet Monitoring deployment. It is not offered as a public service.

Google data accessed

With the operator's consent, the integration requests Gmail read-only access (https://www.googleapis.com/auth/gmail.readonly). It watches the operator's inbox for changes and reads alert messages, their sender, subject, authentication results, labels, and body. It cannot send, delete, or modify email.

Purpose and use

The integration uses this data to identify Grafana alert notifications, check their authenticity, investigate the corresponding service health through Grafana, and prepare an assessment for the operator. Non-Grafana mail is not sent to the incident-analysis agent. Google Cloud Pub/Sub receives a mailbox address and Gmail history identifier for event delivery, not message bodies.

Sharing and processing

Relevant Grafana alert contents and diagnostic context may be processed by the operator's configured AI model provider to generate an assessment. The resulting summary is delivered to the operator's encrypted Matrix room. Google user data is not sold, used for advertising, or shared with data brokers. It is used only to provide this operator-requested monitoring function, subject to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

OAuth credentials are stored in access-restricted files on the operator-controlled host. A local database stores Gmail history cursors and processed message IDs to prevent duplicate notifications. Hermes may retain agent transcripts, diagnostics, and delivered summaries according to the operator's local retention settings; the encrypted Matrix room retains delivered messages according to that room's settings. The operator controls these systems and can delete local records and messages.

Security and control

Google API calls use HTTPS. Credentials are not placed in public code, alert messages, or this website. The operator can revoke this app's access at Google Account connections, stop the local integration, and delete its local credentials and records.

Contact

For privacy questions or deletion requests, contact hermes.tretiak@gmail.com.
